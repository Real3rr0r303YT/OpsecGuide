PHASE 03 // WORKSTATION HARDENING & TAILS

ThinkPad Coreboot-Anleitung & Tails OS

ThinkPad Coreboot Guide & Tails OS

  1. Unterstützte Modelle und Details findest du im offiziellen Coreboot Mainboard Matrix sowie der Libreboot Dokumentation.

  2. Vor dem Anschließen des Clips: Akku und CMOS-Batterie zwingend trennen! Nutze einen externen Rechner mit flashrom (siehe offizielle Flashrom Doku).

    Terminal
    # 1. Chip erkennen und Backup mehrfach erstellen (Hashes MÜSSEN identisch sein!)
sudo flashrom -p ch341a_spi -r backup1.bin
sudo flashrom -p ch341a_spi -r backup2.bin
sha256sum backup1.bin backup2.bin

# 2. Coreboot / Libreboot Image aufspielen
sudo flashrom -p ch341a_spi -w coreboot.rom
    [ACHTUNG]: Ein fehlerhafter Flashvorgang brickt das Mainboard, sofern kein funktionierendes Backup vorliegt.

  3. Für sensible Einzelsessions ohne jegliche Spuren auf der Festplatte: Installiere Tails OS auf einem USB-Stick. Der gesamte Datenverkehr wird standardmäßig über das Tor-Netzwerk geleitet, und nach dem Herunterfahren hinterlässt das System absolut keine Spuren auf dem Host-Gerät.
