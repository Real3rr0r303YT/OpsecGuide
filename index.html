PHASE_00 // PREFLIGHT

Threat Model zuerst

Threat Model First

OpSec ist kein Produkt, sondern ein Prozess. Bevor du irgendetwas kaufst oder flasht, beantworte vier Fragen. Ohne Bedrohungsmodell baust du eine Festung mit offener Hintertür.

OpSec is not a product; it's a process. Before buying or flashing anything, answer four questions. Without a threat model, you're building a fortress with an open back door.

01 // Was schützen?

Identität, Standort, Kommunikation, Kontakte, Dateien, Finanzen.

02 // Vor wem?

Werbe-Tracker, Datenhändler, Stalker, Arbeitgeber, Kriminelle, staatliche Akteure.

03 // Wie wahrscheinlich?

Massenüberwachung trifft alle. Gezielte Angriffe sind seltener, aber teurer abzuwehren.

04 // Was kostet ein Leak?

Von nervig (Spam) bis existenziell (Doxxing, physische Gefahr).

01 // What to protect?

Identity, location, communication, contacts, files, finances.

02 // From whom?

Ad trackers, data brokers, stalkers, employers, criminals, state actors.

03 // How likely?

Mass surveillance affects everyone. Targeted attacks are rarer but harder to defend against.

04 // Impact of a leak?

From annoying (spam) to existential (doxxing, physical danger).

PHASE_01 // PHYSICAL OPSEC

Hardware-Anonymisierung

Hardware Anonymization

    • Keine Karten, kein PayPal, keine Kundenkarte, kein Name auf der Quittung.
    • Unterstütztes Pixel-Modell wählen (siehe grapheneos.org/faq).
    • Auf entsperrbaren Bootloader achten (keine gesperrten Carrier-Varianten).

  2. Provider verknüpfen IMEI + IMSI sofort. Nutze Daten-eSIMs ohne KYC oder betreibe das Gerät nur über anonymes WLAN.

    • No credit cards, no PayPal, no loyalty cards, no name on receipts.
    • Select a supported Pixel device (see grapheneos.org/faq).
    • Ensure bootloader is unlockable (avoid locked carrier models).

  2. Carriers map IMEI + IMSI instantly. Use no-KYC eSIMs or run the device strictly via anonymous Wi-Fi.
